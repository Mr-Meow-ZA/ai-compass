# Product Vision

## Purpose

AI Compass should help a user answer four questions:

1. **What is happening in AI?**
2. **What does it mean?**
3. **How do I use it?**
4. **Which tools and approaches fit my needs?**

News alone answers only the first question. The durable value of AI Compass comes from connecting current developments to trustworthy explanations, practical guides, references, comparisons and reusable workflows.

## Audiences

### Beginner

Needs clear explanations, safe starting points, learning paths, definitions and practical first projects.

### Capable everyday user

Needs tips, workflows, comparisons, prompt patterns, integrations and curated tools.

### Experienced user or builder

Needs primary sources, repositories, model changes, technical comparisons, architecture references and deeper implementation guides.

## Core experience

The homepage should be a balanced dashboard containing:

- Continue learning.
- Recommended guides.
- Popular tips and workflows.
- A reference concept or glossary topic.
- Useful tools and repositories.
- Recently updated comparisons.
- A compact latest-news module.
- New videos and external resources.

News should generally occupy about 20–30% of homepage attention, rather than becoming the entire product identity.

## Navigation model

- Home
- Learn
- Guides
- Tips & Tricks
- Reference
- Tools & Models
- Resources
- News
- Community

## Editorial identity

AI Compass should feel calm, technically credible and useful. It should avoid:

- Generic AI gradients and excessive rounded cards.
- Sensational headlines.
- Unverified rankings.
- Repackaged third-party content.
- Artificial content volume.
- Hiding important source or date information.
