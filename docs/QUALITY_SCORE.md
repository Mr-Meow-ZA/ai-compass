# Quality Score

Every meaningful product review should score the site from 1–10 for:

- Mobile usability
- Navigation
- Visual design
- Accessibility
- Performance
- Reliability
- Information architecture
- Search and filtering
- Content discovery
- Trustworthiness
- Usefulness to beginners
- Usefulness to experienced AI users

## Scoring rule

A score of 9 requires evidence, not aspiration. Record:

- Routes tested
- Viewports tested
- Interactions tested
- JavaScript errors
- Broken links
- Accessibility findings
- Performance observations
- Remaining limitations

The current front end is functional, but its information architecture is not yet at the intended target because the news feed dominates the experience and several planned content pillars are not properly separated.
